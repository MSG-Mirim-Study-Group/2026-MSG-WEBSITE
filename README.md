# 2026 MSG 전공 동아리 웹사이트

2026 MSG 전공 동아리를 위한 공식 웹사이트입니다.  
HTML, CSS, JavaScript로 개발되었으며, 동아리 소개, 활동 내역, 멤버 정보, 공지사항 등을 제공합니다.

## 📚 프로젝트 소개

- 동아리 활동을 홍보하고 정보를 공유하기 위한 웹사이트입니다.
- 방문자는 동아리 활동 내역, 공지사항, 멤버 소개 등을 확인할 수 있습니다.

## 🛠️ 기술 스택

- **Frontend:**  
  - HTML  
  - CSS  
  - JavaScript

## 🌟 주요 기능

- 동아리 소개 및 연혁
- 멤버 소개 페이지
- 활동 내역 및 사진/동영상 아카이브
- 공지사항 및 게시판
- 문의 및 연락처 정보

## 🚀 시작하기

1. 이 리포지토리를 클론하세요:

    ```bash
    git clone https://github.com/sangyeon08/2026-MSG-WEBSITE.git
    ```

2. 프로젝트 폴더로 이동하세요:

    ```bash
    cd 2026-MSG-WEBSITE
    ```

3. (필요시) 로컬 서버를 실행하세요.  
   예시: [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) VSCode 확장 사용

4. `index.html` 파일을 브라우저에서 열어 사이트를 확인하세요.
